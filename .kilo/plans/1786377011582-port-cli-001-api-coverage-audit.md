# PORT-CLI-001: Kiota API Coverage Audit

## Task Identifier
PORT-CLI-001 — Kiota API Coverage Audit

## Executive Summary

The Kiota migration is blocked by **48 compilation errors** across 13 handler service files. These errors fall into **five distinct categories**:

1. **Missing request builders** (endpoints not generated by Kiota)
2. **Missing model properties** (generated models differ from expected structure)
3. **Missing methods on request builders** (expected methods not generated)
4. **Type mismatch errors** (C# type inference issues)
5. **Missing LINQ using directives** (simple fix)

**Critical finding**: Several endpoints called by the Visual Studio code **do not exist in the OpenAPI specification**:
- `/auth/logout` — Not in OpenAPI, not in server code
- `/workstyle` — Not in OpenAPI, not in server code  
- `/model` (root) — Not in OpenAPI; only `/kilo/models/images` and `/indexing/models` exist
- `/notification` (root) — Exists as `/kilo/notifications` in OpenAPI

**Recommendation**: The Visual Studio implementation contains **legacy/deprecated endpoint references** that VS Code no longer uses. These should be classified as **Category E (Legacy/Unused)** and removed rather than implementing raw HTTP fallbacks.

**Error 1-2**: `Auth.Logout.PostAsync()` does not exist

```csharp

```

**Analysis**:
- OpenAPI has only `/auth/{providerID}` — no `/auth/logout`
- Server code has no logout route
- VS Code search shows only telemetry constants mentioning "logout"
- **Classification**: Category E (Legacy/Unused)

**Recommendation**: Remove the `HandleLogoutAsync` method entirely. If logout is needed, it should be implemented via the Kilo gateway auth flow, not a backend endpoint.
