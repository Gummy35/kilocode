## 1. Executive Summary

This plan identifies the VS Code CLI/HTTP communication layer components and maps them to the existing Visual Studio implementation. The VS Code implementation is the source of truth.

**Key Finding:** The Visual Studio extension has a solid foundation for the CLI/HTTP layer but is missing several features present in VS Code, particularly around session visibility tracking and directory management.

## 2. VS Code Source Components

### 2.1 ServerManager (`server-manager.ts`)

| Aspect | VS Code Implementation |
|--------|----------------------|
| **File** | `packages/kilo-vscode/src/services/cli-backend/server-manager.ts` |
| **Spawn** | `spawn(cliPath, ["serve", "--port", "0"])` |
| **Port discovery** | Regex parse stdout for `listening on http://127.0.0.1:PORT` |

## 11. Environment Variable Classification

Based on inspection of `server-manager.ts`, environment variables are classified as follows:

### CLI-Functional (Must Preserve)

| Variable | Purpose | Visual Studio Action |
|----------|---------|---------------------|
| `KILO_SERVER_PASSWORD` | CLI authentication | **REQUIRED** - Generate random password |
| `KILO_PARENT_PID` | Parent watchdog (CLI exits if extension host dies) | **REQUIRED** - Set to extension process PID |
| `MIMALLOC_PURGE_DELAY` | Memory allocator behavior (prevents RSS growth) | **REQUIRED** - Set to "0" |
| `NODE_USE_SYSTEM_CA` | TLS trust store | **REQUIRED** - Set to "1" |
| `NODE_EXTRA_CA_CERTS` | Custom CA bundle (if configured) | **REQUIRED** - Read from VS Code config |
| `NODE_TLS_REJECT_UNAUTHORIZED` | TLS verification opt-out | **REQUIRED** - Honor VS Code proxyStrictSSL |
| `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY` | Corporate proxy support | **REQUIRED** - Map from VS Code http.* settings |

### VS Code-Specific (Not Required for Visual Studio)

| Variable | Purpose | Visual Studio Action |
|----------|---------|---------------------|
| `KILO_VSCODE_VERSION` | VS Code version metadata | **NOT REQUIRED** - VS Code specific |
| `KILO_EDITOR_NAME` | Editor name (includes VS Code version) | **NOT REQUIRED** - VS Code specific |
| `KILO_VSCODE_VERSION` | Duplicate VS Code version | **NOT REQUIRED** - VS Code specific |
| `KILO_TELEMETRY_LEVEL` | Telemetry based on VS Code settings | **ADAPT** - Map to VS Code telemetry |
| `KILO_MACHINE_ID` | VS Code machine ID | **ADAPT** - Use VS machine ID if available |
| `KILO_APP_NAME` | Application name | **OPTIONAL** - Can set to "kilo-code" |
| `KILO_APP_VERSION` | Extension version | **OPTIONAL** - Can set from VSIX manifest |
| `KILOCODE_VERSION` | Extension version | **OPTIONAL** - Can set from VSIX manifest |
| `KILOCODE_EDITOR_NAME` | Editor name with version | **NOT REQUIRED** - VS Code specific |
| `KILO_ENABLE_QUESTION_TOOL` | VS Code question tool flag | **NOT REQUIRED** - VS Code specific |
| `KILOCODE_FEATURE` | Feature flag for VS Code | **NOT REQUIRED** - VS Code specific |
| `KILO_DISABLE_CLAUDE_CODE` | Claude compatibility flag | **OPTIONAL** - If relevant to VS |
| `KILO_DISABLE_CODEBASE_INDEXING` | Indexing control | **ADAPT** - If indexing is supported |
| `KILO_DISABLE_CHANNEL_DB` | Channel DB control | **OPTIONAL** - If relevant |

### Visual Studio Equivalents Needed

| VS Code Variable | Visual Studio Equivalent |
|------------------|-------------------------|
| `KILO_CLIENT=vscode` | `KILO_CLIENT=visualstudio` |
| `KILO_PLATFORM=vscode` | `KILO_PLATFORM=visualstudio` |
| `VS Code http.proxy` | `HTTP_PROXY` / `HTTPS_PROXY` |
| `VS Code http.noProxy` | `NO_PROXY` |
| `VS Code http.proxyStrictSSL` | `NODE_TLS_REJECT_UNAUTHORIZED` |
